# ECOSYSTEM LAB — ノーマル／AI①逃走進化／AI②群れ進化

草食の緑100匹、肉食の赤20匹を基本条件とする、ブラウザ完結型の2D生態系シミュレーターです。ノーマル（進化なし）とAI①（緑の逃走進化）を別々の世界で観察できます。青を含む古いモデルは履歴として残しています。

> 本作品は**仮想生態系**です。ノーマルはルール制御、AI①は小型のニューラルネットワークを遺伝・突然変異で進化させるニューロエボリューションです。科学的な実生態系の予測モデルではありません。

## 使い方

1. `index.html` をブラウザで開く。分割版では `src/sim-core.js` と `src/ui.js` が同じフォルダ構成で必要です。
2. 初期設定は緑100・赤20・青0。ノーマルとAI①で個体・乱数進行・統計・停止状態を独立して保持します。1× / 5× / 20×、停止、+1/+10/+100日、ズーム、個体追跡に対応。
3. `乱数シード`を固定すると同じ条件を再現でき、`🎲 別の展開`でシードを変更できます。
4. 緑・赤の個体数グラフ、出生・死因・捕食などの詳細統計と、AI①の世代・突然変異指標を確認できます。CSV出力や同条件の10回比較も可能です。
5. スマホでは一括検証に数秒〜数十秒かかる可能性があります。

## コード構成

- `src/sim-core.js` — シード固定・表示処理なしのシミュレーション本体。Nodeでテスト可能。
- `src/ui.js` — Canvas描画、操作、グラフ、CSV、再実験機能。
- `index.html` — 画面。追加インストールなし。
- `tests/smoke.test.js` — 再現性、出生死亡集計、ステータス、境界条件の検証。
- `tests/montecarlo.js` — 100日間の独立した乱数シードでの複数回検証。
- `docs/SPEC.md` — ルールと主な数値。

## テスト

Node.js 18以降を利用：

```bash
node tests/smoke.test.js
node tests/montecarlo.js 50
```

依存パッケージなし。GitHub Pages等で公開する場合は `index.html` をエントリーポイントとしてそのまま配置できます。

## 制作における注意

- 100日間の結果はシード・環境条件・更新間隔にも依存します。同じ条件で複数回の実験を比較してください。
- 「捕食成功率」は追跡開始回数に対する捕食数。命中率とは異なります。
- 捕食者は赤・青同士では攻撃しません。競争は緑という共通の獲物を介する間接競争です。
- 草食は捕食者の攻撃を受けた時だけ一定確率で反撃します。
- 各個体は親の能力を遺伝しません（個体差は誕生時に独立抽選）。
- 画面上の最大個体数は処理負荷対策の上限があり、極端な条件変更下では結果に影響します。

## v0.3 — 餓死・壁際・統計の改良

- 毎ステップ、エネルギーを消費した後に採食／捕食の機会を設け、食べられなかった場合に餓死させます。
- 壁際で逃げ続ける個体は、壁沿い・内側に進む方向へ補正します。
- エネルギーが極端に減った緑は、遠くの捕食者より採食を優先する行動をとります。
- 個体日（延べ生存時間）を記録。赤と青の比較に100個体日あたり捕食数を使えます。
- 草が近くに残っている状態の餓死も別途記録。近くにある草が実際に食べられたとは限りません。

**100回の実験**：乱数シード 20261117〜20261216、100日間で赤青共存45回、赤のみ12回、青のみ7回、双方絶滅36回。平均最終個体数は緑124.8、赤5.2、青2.3。捕食効率は赤14.23、青33.75（100個体日あたり）。緑の餓死の96.6%で近傍に草が残っていました。これは改善しきれていない行動上の問題を示唆し、現実の生態系を再現している証拠ではありません。

再検証：`node tests/montecarlo.js 100`。**本版にはAI学習機能はまだ含まれません。**

- **AI① 逃走進化**：緑の逃走判断をニューラルネットワーク＋遺伝・変異で進化させる実験。**実装済み**。

## 100日を超えて継続するノーマル実験

ノーマルタブの表示はDAY100で止まりません。再生・一時停止・+1日・+10日・+100日で101日目以降も生態系を継続して観察できます。日別グラフは自動で横軸を拡張し、400日を超えると直近400日間を表示します。CSVには開始からの全日別データが残ります。

100日は赤の頭数バランスや将来のAI①/AI②の**比較基準日**として残しますが、実際の観察はそれ以降も自由に続けられます。長期間では生物が全滅する場合もあり、その場合は自然に復活させません。

通常の集計・CIの100日実験は従来どおり有限の100日間です。シミュレーションエンジンに `duration: Infinity` を渡した場合のみ上限なく進みます。`run()` は無期限モードでは一度の呼び出しで100日分を進める安全な既定値を使います。

### DAY100で一度だけ停止する観察モード

ノーマルタブはDAY0から再生すると、**DAY100で自動的に一時停止**します。この時点で生物・草・個体数統計はリセットされません。「▶ 100日以降を再生」を押すと、その**同じ生態系**がDAY101以降も連続再生し、DAY200やDAY300では自動停止しません。

日数送りで初めてDAY100をまたぐ場合も一旦DAY100で停止し、以降は日数送りも使えます。「↻ 最初から」を押した場合に限りこの自動停止フラグを初期化します。AI①も同じDAY100停止・▶再開仕様です。AI②は未実装です。

## AI① ニューロエボリューション仕様（2026-11-17）

- 緑1匹ごとに10入力・8隠れニューロン・3出力、合計115個の重みを持つ小型ニューラルネットワークを搭載。
- 入力：近い敵との相対位置、敵の向き、敵への近接度、エネルギー、HP、自分の位置、近隣の草。
- 出力：逃走方向の角度補正、横方向の回避補正、警戒・採食切り替えの調整。基礎的な逃走反射は全個体に共通のまま、判断の違いを進化させます。
- 出生時、親の重みを引き継いで確率8%／重みで突然変異（最大±0.34）。自然な生存・繁殖が選択圧となり、報酬関数や外部AI APIは利用しません。
- 赤の捕食・繁殖はノーマルと同じ固定行動、脳の遺伝・進化処理は赤に適用しません。
- AI①のメトリクス：生存緑の平均世代・最高世代・継承した子どもの数・変異した子どもの数・危険感知時間中の逃走割合・標準化した固定状況での平均警戒出力。CSVにも日別の関連値を記録。
- **注意**：AIが進化する仕組みがあることと、「100日で生存率が改善する」ことは異なります。進化速度や最終的な有利不利は複数シードで別途検証してください。個体が一生の中で学び直す強化学習（PPO等）ではありません。

## 結果まとめ・1枚スクショ用表示（2026-11-17）

ノーマルまたはAI①タブで **「📸 結果まとめ」** をタップすると、観察中の世界を一時停止し、全画面のコンパクトな結果ボードを開きます。iPhone画面上でのスクリーンショットと、**「1枚の画像で保存（PNG）」**による1080×1500の独立した画像出力に対応しています。戻るボタンで同じ実験に復帰できます（実験は一時停止したまま）。

- 結果ボード：DAY・シード・最終生存数・赤緑の推移グラフ・出生・捕食死・餓死・赤の捕食成功率。
- AI①で追加：最高到達世代・**過去に生存していた緑の平均世代のピーク**・変異した子の数・危険時の逃走割合。
- **何を学習？** 位置・敵の向き／距離・空腹・HP・草を10入力で取得し、8神経を経て3値（逃走タイミング、逃走角度、横回避）を出力。115個の重みを親から子に継承し、各重み8%の確率で突然変異。報酬による生涯内の強化学習ではなく世代交代に伴う選択。
- **赤の捕食・繁殖・寿命・初期能力のルールはノーマルとAI①で変更なし**。ただし緑の逃走成功率や個体数が変わると、実際の赤の出生・死亡・個体数は間接的に変わり得ます。
- シミュレーションのCanvasは幅960×高さ600のままでサイズ変更していません。AI①の巨大な情報表示を映像の手前から外し、詳細を結果画面に集約しました。
- 緑が絶滅すると現在の平均世代は計算できないため、過去の平均世代の最大値（ピーク）を別途記録・表示します。「ピーク平均世代」はAIの成功率を示す数値ではありません。
