# ECOSYSTEM LAB — ノーマル／AI①逃走進化／AI②群れ進化

草食の緑100匹、肉食の赤20匹を基本条件とする、ブラウザ完結型の2D生態系シミュレーターです。ノーマル（進化なし）とAI①（緑の逃走進化）を別々の世界で観察できます。青を含む古いモデルは履歴として残しています。

> 本作品は**仮想生態系**です。ノーマルはルール制御、AI①は小型のニューラルネットワークを遺伝・突然変異で進化させるニューロエボリューションです。科学的な実生態系の予測モデルではありません。

## 使い方

1. `index.html` をブラウザで開く。分割版では `src/sim-core.js` と `src/ui.js` が同じフォルダ構成で必要です。
2. 初期設定は緑100・赤20・青0。ノーマルとAI①で個体・乱数進行・統計・停止状態を独立して保持します。1× / 5× / 20×、停止、+1/+10/+100日、ズーム、個体追跡に対応。
3. `乱数シード`を固定すると同じ条件を再現でき、`🎲 別の展開`でシードを変更できます。
4. 緑・赤の個体数グラフ、出生・死因・捕食などの詳細統計と、AI①の世代・突然変異指標を確認できます。CSV出力や同条件の10回比較も可能です。
5. スマホでは一括検証に数秒〜数十秒かかる可能性があります。

## コード構成

- `src/sim-core.js` — シード固定・表示処理なしのシミュレーション本体。Nodeでテスト可能。
- `src/ui.js` — Canvas描画、操作、グラフ、CSV、再実験機能。
- `index.html` — 画面。追加インストールなし。
- `tests/smoke.test.js` — 再現性、出生死亡集計、ステータス、境界条件の検証。
- `tests/montecarlo.js` — 100日間の独立した乱数シードでの複数回検証。
- `docs/SPEC.md` — ルールと主な数値。

## テスト

Node.js 18以降を利用：

```bash
node tests/smoke.test.js
node tests/montecarlo.js 50
```

依存パッケージなし。GitHub Pages等で公開する場合は `index.html` をエントリーポイントとしてそのまま配置できます。

## 制作における注意

- 100日間の結果はシード・環境条件・更新間隔にも依存します。同じ条件で複数回の実験を比較してください。
- 「捕食成功率」は追跡開始回数に対する捕食数。命中率とは異なります。
- 捕食者は赤・青同士では攻撃しません。競争は緑という共通の獲物を介する間接競争です。
- 草食は捕食者の攻撃を受けた時だけ一定確率で反撃します。
- 各個体は親の能力を遺伝しません（個体差は誕生時に独立抽選）。
- 画面上の最大個体数は処理負荷対策の上限があり、極端な条件変更下では結果に影響します。

## v0.3 — 餓死・壁際・統計の改良

- 毎ステップ、エネルギーを消費した後に採食／捕食の機会を設け、食べられなかった場合に餓死させます。
- 壁際で逃げ続ける個体は、壁沿い・内側に進む方向へ補正します。
- エネルギーが極端に減った緑は、遠くの捕食者より採食を優先する行動をとります。
- 個体日（延べ生存時間）を記録。赤と青の比較に100個体日あたり捕食数を使えます。
- 草が近くに残っている状態の餓死も別途記録。近くにある草が実際に食べられたとは限りません。

**100回の実験**：乱数シード 20261117〜20261216、100日間で赤青共存45回、赤のみ12回、青のみ7回、双方絶滅36回。平均最終個体数は緑124.8、赤5.2、青2.3。捕食効率は赤14.23、青33.75（100個体日あたり）。緑の餓死の96.6%で近傍に草が残っていました。これは改善しきれていない行動上の問題を示唆し、現実の生態系を再現している証拠ではありません。

## 100日を超えて継続するノーマル実験

ノーマルタブの表示はDAY100で止まりません。再生・一時停止・+1日・+10日・+100日で101日目以降も生態系を継続して観察できます。日別グラフは自動で横軸を拡張し、400日を超えると直近400日間を表示します。CSVには開始からの全日別データが残ります。

100日は赤の頭数バランスや将来のAI①/AI②の**比較基準日**として残しますが、実際の観察はそれ以降も自由に続けられます。長期間では生物が全滅する場合もあり、その場合は自然に復活させません。

通常の集計・CIの100日実験は従来どおり有限の100日間です。シミュレーションエンジンに `duration: Infinity` を渡した場合のみ上限なく進みます。`run()` は無期限モードでは一度の呼び出しで100日分を進める安全な既定値を使います。

### DAY100で一度だけ停止する観察モード

ノーマルタブはDAY0から再生すると、**DAY100で自動的に一時停止**します。この時点で生物・草・個体数統計はリセットされません。「▶ 100日以降を再生」を押すと、その**同じ生態系**がDAY101以降も連続再生し、DAY200やDAY300では自動停止しません。

日数送りで初めてDAY100をまたぐ場合も一旦DAY100で停止し、以降は日数送りも使えます。「↻ 最初から」を押した場合に限りこの自動停止フラグを初期化します。AI①も同じDAY100停止・▶再開仕様です。AI②は未実装です。

## AI① ニューロエボリューション仕様（2026-11-17）

- 緑1匹ごとに10入力・8隠れニューロン・3出力、合計115個の重みを持つ小型ニューラルネットワークを搭載。
- 入力：近い敵との相対位置、敵の向き、敵への近接度、エネルギー、HP、自分の位置、近隣の草。
- 出力：逃走方向の角度補正、横方向の回避補正、警戒・採食切り替えの調整。基礎的な逃走反射は全個体に共通のまま、判断の違いを進化させます。
- 出生時、親の重みを引き継いで確率2%／重みで突然変異（最大±0.10）。自然な生存・繁殖が選択圧となり、報酬関数や外部AI APIは利用しません。
- 赤の捕食・繁殖はノーマルと同じ固定行動、脳の遺伝・進化処理は赤に適用しません。
- AI①のメトリクス：生存緑の平均世代・最高世代・継承した子どもの数・変異した子どもの数・危険感知時間中の逃走割合・標準化した固定状況での平均警戒出力。CSVにも日別の関連値を記録。
- **注意**：AIが進化する仕組みがあることと、「100日で生存率が改善する」ことは異なります。進化速度や最終的な有利不利は複数シードで別途検証してください。個体が一生の中で学び直す強化学習（PPO等）ではありません。

## AI①突然変異の改善検証（2026-11-19）

- 5条件×100シードの探索実験を実施し、別100シードで確認。その後、選定した2%・±0.10設定を**さらに未使用の100シードで事前指定比較**した。
- 現行8%・±0.34では、最後の100シードで緑がDAY100まで生き残ったのは71回、2%・±0.10では84回。最終個体数平均は54.17匹→82.27匹。
- 300シードの合計では、緑のDAY100生存が旧設定222回、新設定250回。赤の能力・捕食・繁殖ルールとマップ条件は同じ。
- 新設定は**緑のニューラルネットワークの突然変異率・幅だけ**を変更。個体が自分の一生で学習する方式ではなく、親から子への遺伝・自然選択は従来どおり。
- 新設定はこの仮想モデル内での検証結果。今後のAI②との比較では同じ赤・環境条件を使い、100日間の複数シードを検証すること。
- 再現用：`node tests/escape-mutation-sweep.js 0 25 20261317 baseline,p02_a010`（残りのシード範囲はoffset=25,50,75）。履歴データは `reports/escape_mutation_sweep_100_seeds.json`、`reports/escape_mutation_sweep_holdout_100_seeds.json`、`reports/escape_mutation_sweep_third_100_seeds.json`。

## AI①逃走戦術の記録（2026-11-19）

赤の行動、捕食・繁殖、寿命、速度は**一切変更せず**、AI①に観測専用の計測処理を追加しました。緑の逃走行動も変更していません。既存のシミュレーション映像は960×600のままです。

### 記録する値

| 項目 | 定義 |
|---|---|
| 逃走開始距離（px） | 直前の更新では逃走していなかった緑が、赤を感知して新たに逃走を始める瞬間の赤‐緑間距離。直前位置から算出 |
| 方向転換角度（°） | その逃走開始時、緑の直前の進行方向と、逃走して実際に移動した方向の最小角度差（0〜180°）。位置が動かなかった記録は角度平均から除く |
| 赤から真逆方向との偏差（°） | 逃走開始時の実際の移動方向と、赤から真逆に向かう方向の角度差（0〜180°）。世代別CSVに含む |
| 赤の追跡開始 | 赤が空腹のときに緑を標的として選び、追跡を開始した回数 |
| 赤の追跡距離離脱 | その赤が標的を追跡中、緑が生存した状態で赤から **200×赤の視野倍率** より遠ざかり、既存の追跡判定が解除された回数 |
| 赤による捕食 | 同じ赤が追跡中の緑を捕食死亡させた回数 |
| ほかの追跡終了 | 赤の死亡、ほかの原因で標的が消失、空腹条件解除などで追跡が終了した回数 |
| 距離離脱率 | **距離離脱÷（距離離脱＋その赤による捕食）**。ほかの終了とまだ継続中の追跡を分母から除外 |

「距離離脱率」は赤の**追跡距離超過による追跡解除の記録**であり、全体の逃走成功率・長期生存率とは異なります。このモデルでは赤の方が移動速度が速く、実際の記録で距離離脱が0回となる可能性があります。0回を都合よく別の指標に置き換えません。

逃走開始時の距離と角度、追跡開始・終了について、すべてイベントごとに個体IDと世代、ゲーム内日数を記録。個別ログはブラウザ負荷対策で最大20,000行まで（超過件数は結果画面に表示）、**日別・世代別の集計は全期間・全イベント**を保持します。世代別は実際の世代番号でも記録し、結果まとめでは0／1〜2／3〜5／6+世代に集約して表示。

### 参照・保存方法

- **📸 結果まとめ**：AI①に「逃走開始距離」「方向転換角度」「追跡距離離脱率」「世代グループ別の実測値」を表示。1枚のPNGにも収録。
- **↓ 統計CSV**：1日刻みで、ゲーム開始からの累計逃走開始数、平均開始距離、平均転換角、赤から真逆方向との偏差、追跡開始・距離離脱・捕食・その他、距離離脱率を記録。
- **↓ 逃走ログCSV**：各逃走開始、赤の追跡開始・終了イベントを時刻・緑ID・世代・赤ID・距離・角度・終了理由・追跡継続時間で出力（上限20,000件）。
- **↓ 世代別CSV**（結果まとめ内）：**実際の世代番号ごと**の逃走開始数・距離・角度・追跡結果をすべて出力。

この計測は観測値を保存するだけで、緑や赤がニューラルネットワークを更新する処理には影響しません。実際に世代が進むにつれて逃走が巧みになったかは、各世代の捕食者密度・餌・経過日数などの環境差も考慮した複数シードの分析が必要です。

## AI①：赤の接近後1日の無被弾生存率（2026-11-19）

「逃走開始・方向転換・追跡解除」という行動指標に加えて、**結果として攻撃を回避できたか**を計測する観測専用の指標を実装しました。

- **開始条件**：赤が緑の周囲120px以内に入る（追跡していない赤も対象）。同じ接近区間では何度もカウントしない。
- **成功**：開始後、ゲーム内の**1日間**、赤から攻撃を一度も受けずに緑が生存した。
- **失敗**：1日以内に赤の攻撃を受けた（致死・非致死を問わない）、または攻撃以外の理由で死亡した。
- **未決着**：観測中のままDAY100等で実験が終わった場合。生存率の分母から除外。
- **計算**：無被弾生存数 ÷（無被弾生存＋被弾＋その他死亡）。各個体の生存判定は赤の攻撃処理で直接観測する。
- **制約**：近づいても捕食しない赤も含むため、**「赤に追跡された場合の逃走成功率」ではありません**。個体・接近イベント間には依存があり、単純にイベント数を独立試行として扱わないこと。

### 実測結果（初期緑100・赤20、100シード×2条件、各100日間）

| 指標 | 現行の進化AI① | 親のAIを変異なしで継承 |
|---|---:|---:|
| 1日無被弾生存率（完了した接近単位） | **95.14%** | **95.24%** |
| 無被弾生存した接近件数 | 245,749 | 276,148 |
| 途中で赤に攻撃された件数 | 6,198 | 6,391 |
| その他の原因で死亡 | 6,362 | 7,403 |
| 観測完了前に実験終了 | 1,005 | 1,391 |

100シードの対応比較で進化−変異なしの平均率差は **−0.08ポイント**（簡易95%区間−0.25〜+0.09ポイント）。突然変異による無被弾生存率の改善は確認されなかった。

- AI①の「📸 結果まとめ」とPNGに1日無被弾生存率、および世代別の率を表示。
- 日別統計CSVに120px以内の接近開始／無被弾生存／被弾／その他死亡／未決着を追加。世代別CSVにも含める。
- 個別イベントCSVに接近開始日・距離・エネルギー・1日後の結果を追記。公開ブラウザの個別ログは20,000件上限、日次・世代別の累積値は上限なし。
- [100シード検証レポート](reports/attackfree_1day_100_seeds_summary.md)、[比較CSV](reports/attackfree_1day_100_seeds.csv)、[詳細JSON](reports/attackfree_1day_100_seeds.json)。
- [再現用Nodeスクリプト](tests/escape-attackfree-study.js)を使い `node tests/escape-attackfree-study.js 0 25`（offsetを0,25,50,75）で再検証できる。

赤の行動・捕食・繁殖・寿命・能力、緑の行動AI・変異率、シミュレーション画面960×600は変更せず、元の100シードの生存数・出生・死亡数と全件一致することを確認しています。

## AI①の追跡回避改善（2026-11-19）

赤が緑を実際に標的として選んだ瞬間から1ゲーム日、攻撃を受けずに生存できた割合を計測。2026-11-19の25シード探索＋**未使用100シードの本検証**で、AI①の緑だけに早期警戒・逃走角度の過度な変化の抑制を適用しました。**通常のAI①は改良版 `escapePolicy:'wide'` が標準**。研究用に旧版 `escapePolicy:'baseline'` も残しています。

| 100シードの項目 | 旧AI①（baseline） | 改良AI①（wide） |
|---|---:|---:|
| 赤の追跡開始後1日・無被弾生存率 | 15.33% | **23.00%** |
| DAY100まで緑が生存した試行 | 78/100 | **98/100** |
| 赤と緑がともに生存 | 62/100 | **88/100** |
| 緑の最終平均個体数 | 66.43 | **190.18** |
| 緑の捕食死・平均 | 450.38 | **334.70** |
| 緑の餓死・平均 | **271.90** | 381.50 |

実装差分は、緑の逃走判定しきい値 `0.39+空腹度×0.25` → `0.25+空腹度×0.19`、神経回路由来の旋回係数 `1.05`→`0.65`、横回避係数 `0.55`→`0.30`。**赤の速度・寿命・捕食・繁殖、緑の速度や基礎能力、遺伝・変異設定（2%・±0.10）は変更なし。**

ただしこれは**開発者が設計した逃走判断の改善**で、進化そのものが逃走技術を獲得した証拠ではありません。同じ改良ルールで突然変異あり／なしを比較すると無被弾生存率23.00%／22.49%、対応100シードの平均差+0.50ポイント（近似95%区間−0.40〜+1.41ポイント）で、進化効果は未実証です。

**次の改善課題は餓死の増加**です。危険でないときの採食をもっと上手に調整し、追跡回避能力を維持したまま飢えを減らす案を対照実験で検証します。続いて壁際の逃走判断と、環境差を取り除いた進化効果の評価。
