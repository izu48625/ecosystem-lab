# ECOSYSTEM LAB — 3種の生存競争

草食の緑100匹、肉食の赤10匹、肉食の青10匹を100日間観察する、ブラウザ完結型の2D生態系シミュレーターです。生物の捕食・反撃・繁殖・寿命・餓死・個体差をシード固定の疑似乱数で計算します。

> 本作品は**ルールベースの仮想生態系**です。科学的な実生態系の予測モデルでも、機械学習AIでもありません。AI学習機能は別フェーズで実装予定です。

## 使い方

1. `index.html` をブラウザで開く。分割版では `src/sim-core.js` と `src/ui.js` が同じフォルダ構成で必要です。
2. 初期設定は緑100・赤10・青10、100日間。1× / 5× / 20×、停止、+1日、ズーム、個体追跡に対応。
3. `乱数シード`を固定すると同じ条件を再現でき、`🎲 別の展開`でシードを変更できます。
4. 赤・青の比較グラフ、出生・死因・捕食などの詳細統計を確認し、CSV出力や同条件の10回比較ができます。
5. スマホでは一括検証に数秒〜数十秒かかる可能性があります。

## コード構成

- `src/sim-core.js` — シード固定・表示処理なしのシミュレーション本体。Nodeでテスト可能。
- `src/ui.js` — Canvas描画、操作、グラフ、CSV、再実験機能。
- `index.html` — 画面。追加インストールなし。
- `tests/smoke.test.js` — 再現性、出生死亡集計、ステータス、境界条件の検証。
- `tests/montecarlo.js` — 100日間の独立した乱数シードでの複数回検証。
- `docs/SPEC.md` — ルールと主な数値。

## テスト

Node.js 18以降を利用：

```bash
node tests/smoke.test.js
node tests/montecarlo.js 50
```

依存パッケージなし。GitHub Pages等で公開する場合は `index.html` をエントリーポイントとしてそのまま配置できます。

## 制作における注意

- 100日間の結果はシード・環境条件・更新間隔にも依存します。同じ条件で複数回の実験を比較してください。
- 「捕食成功率」は追跡開始回数に対する捕食数。命中率とは異なります。
- 捕食者は赤・青同士では攻撃しません。競争は緑という共通の獲物を介する間接競争です。
- 草食は捕食者の攻撃を受けた時だけ一定確率で反撃します。
- 各個体は親の能力を遺伝しません（個体差は誕生時に独立抽選）。
- 画面上の最大個体数は処理負荷対策の上限があり、極端な条件変更下では結果に影響します。
