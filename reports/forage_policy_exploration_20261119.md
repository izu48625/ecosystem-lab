# AI① 採食改善の探索実験（2026-11-19）

## 動機

AI①の現行wide逃走で、近くに草が残るにもかかわらず緑の餓死が多い。初期緑100・赤20・青0、seed 20270001〜20270010、100日（dt=.08）で緑の餓死3,594件。そのうち1,874件（52.1%）は死亡直前の更新で逃走フラグが立っていた。個別計測の「逃走フラグ」は厳密に赤から逃げていたことの証明ではなく、関連の探索指標。

## 候補（まだいずれも標準版には採用しない）

- baseline: 現在のwide逃走・通常採食。研究用の比較基準。
- route: 緑の空腹時、近くの草をより広く探す。危険のある方向は減点。
- adaptive: routeに加え、極度に空腹なら遠距離の赤に対する警戒を少し緩める。ただし近距離は元の早期逃走を維持。
- graze: 危険がなく、足元に草があり空腹なら、一時的に移動せず採食する。
- grazeRoute: routeとgrazeを組み合わせる。
- safeSearch: 赤が250px以内にいないときだけ広域の草探索をする。

変更は **緑AI①の選択的行動** のみ。赤の種族能力・攻撃・繁殖・追跡コード、緑の基本能力・遺伝・変異率、Canvasのサイズは変更しない。 `foragePolicy` のデフォルトは `baseline` のままであり、サイト画面のAI①は従来版で動く。

## 事前探索結果（少数シード、過学習・偶然に注意）

各行はDAY100の緑頭数 / 累積餓死 / 累積捕食死。

| seed | baseline | safeSearch | adaptive | graze | grazeRoute |
|---|---|---|---|---|---|
| 20270001 | 237 / 511 / 318 | 205 / 267 / 329 | 336 / 358 / 340 | 172 / 374 / 381 | 34 / 252 / 498 |
| 20270002 | 313 / 261 / 335 | 176 / 472 / 404 | 39 / 327 / 455 | 145 / 496 / 352 | 214 / 342 / 343 |
| 20270003 | 0 / 303 / 449 | 165 / 498 / 335 | 未測定 | 未測定 | 未測定 |

- routeのseed 20270002は100 / 256 / 381。単一シードでの餓死減少が総生存数を増やすとは限らない。
- safeSearchは1つのシードで改善、別のシードで悪化。現時点では信頼できる優位性は示されていない。
- 各条件で赤の速度や攻撃力は同じでも、緑の位置・数が変わるため赤の実際の出生・捕食結果は変化しうる。
- 「累積餓死」は個体数の増減に左右される。個体日あたり餓死率、DAY100生存、追跡開始後1日無被弾生存率、捕食死を**同時に**評価する。

```bash
node tests/smoke.test.js

node tests/forage-policy-study.js 25 25 20270001 baseline,safeSearch,route,adaptive,graze,grazeRoute
node tests/forage-policy-study.js 50 25 20270001 baseline,safeSearch,route,adaptive,graze,grazeRoute
node tests/forage-policy-study.js 75 25 20270001 baseline,safeSearch,route,adaptive,graze,grazeRoute
```

探索100シードの結果を見た後は、**未使用の100シード**で事前指定した候補とbaselineを比較。評価の優先順位は追跡後無被弾生存率・両種の生存試行率・餓死率・捕食死。新案の結果が不安定または悪化なら変更を標準化しない。

**現状判定：保留。** 少数シードでは一貫した改善がない。mainへの統合や動画用の「改善済み」演出はしない。
